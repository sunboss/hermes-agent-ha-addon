# Home Assistant Add-on: NextChat

NextChat (ChatGPT Next Web) is a fast, lightweight Web UI integrated with Home Assistant via Ingress.

## Features
- **HA Ingress**: Integrated directly into Home Assistant sidebar.
- **Hermes Agent Ready**: Default upstream points to `http://hermes_agent:8642/v1`.
- **Privacy & Lightweight**: Pure client-side UI, extremely fast and low memory usage.
