# Home Assistant Add-on: LobeChat

LobeChat is a modern, open-source AI chat workspace that natively integrates with Home Assistant via Ingress.

## Features
- **HA Ingress**: Integrated in the Home Assistant sidebar.
- **Hermes Agent Connected**: Pre-configured to route to `http://hermes_agent:8642/v1`.
- **Plugin Ecosystem & Multi-Model**: Full OpenAI-compatible API support.
